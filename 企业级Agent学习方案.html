〇、v2 更新要点：这些变化会改变你的学习路线

不是版本号微调，是有破坏性变更。下面 6 项是本次联网核实后必须调整学习内容的，旧教程/旧代码里对应部分已失效。
MCP 2026-07-28（当前规范）
协议改为无状态。移除 initialize/initialized 握手与 Mcp-Session-Id 头，新增 server/discover；方法名走 Mcp-Method / Mcp-Name HTTP 头；server→client 请求改用 MRTR；授权从 DCR 转向 CIMD。影响：W6 学 MCP 必须按新规范建 server，旧的"先握手建会话"写法已废弃。
A2A v1.0.0（2026-03-12 稳定）
首个生产可用版本，由 Linux Foundation 治理，150+ 组织加入。新增签名 Agent Card（JWS）、原生多租户、三种绑定（JSON-RPC / gRPC / HTTP+REST）可各自独立版本号、OAuth Device Code + PKCE。影响：W7 直接用 v1.0 SDK，不必再学 v0.3。
Vercel AI SDK v7.0.74
v7 于 2026-06-25 GA，ESM only（require() 已移除）。v6（2025-12-22）引入 ToolLoopAgent、Output API（generateObject 已废弃）、needsApproval、rerank()、MCP 转 stable。影响：W1–2 直接用 Output API，不要学 generateObject。
Mastra v1（2026-01 发布）
要求 Node.js 22.13.0+，0.x→v1 有大量破坏性变更（Tracing 从 OTel 改为专用 observability 包、Storage/Vectors 方法改 list 模式、MCP tool context 重组）。Mastra Cloud 已拆为 Studio + Server。影响：新项目直接 v1，跳过 0.x 教程。
LangGraph 1.2.x（Python 1.2.11 / JS 1.2.9）
Python 1.2.0 新增 DeltaChannel（checkpoint 只存增量）、per-node timeouts、node error_handler（Saga 补偿）、graceful shutdown、streaming v3。注意：timeouts 与 error handlers 目前是 Python-only，TS 端需用 retry policy 替代。
Daytona 于 2026-06 转闭源
生产代码库闭源后 self-host 不再可用，控制面只能 Daytona 托管。影响：W11 沙箱选型若考虑自托管，改看 OpenSandbox / Microsandbox（均开源自托管），或直接用 E2B / Modal 托管方案。

二、Agent 核心概念扫盲（新手必读）

这是一切的「目录」。W1 通读一遍，后续每学一项回来标注 ✅，形成自己的心智模型。本版新增 2026 新概念

① 基础层

  • LLM / Token：模型、上下文窗口、计费
  • Prompt：System / few-shot / 结构化输出
  • Tool Use：函数调用、JSON Schema
  • Memory：短期(对话) / 长期(向量库)
  • Streaming：SSE / 增量渲染
  • Output API 新：AI SDK v6+ 取代 generateObject

② 编排层

  • Agent Loop：Thought→Action→Observation
  • ToolLoopAgent 新：AI SDK v6 稳定 agent 类
  • StateGraph：节点+边+状态机
  • StateSchema 新：LangGraph.js 1.1 库无关状态定义
  • Durable Execution：checkpoint / resume
  • DeltaChannel 新：只存增量，降 checkpoint 开销
  • HITL / Interrupt：人工审批闸门

③ 多 Agent / 协议

  • Multi-Agent：supervisor / swarm / 辩论
  • MCP 2026-07-28 新：无状态核心、MRTR、CIMD
  • A2A v1.0 新：签名 Agent Card、多租户
  • Send / Command：并行 fanout / 跳转
  • DeepAgent：长程自主 + 全 harness
  • Harness：Agent 运行时/控制平面

④ 知识 / 工程 / 安全

  • RAG：检索增强生成全流程
  • GraphRAG 快照 新：知识图可序列化复用
  • rerank()：AI SDK v6 重排 API
  • Evals：评估集 / LLM-as-judge
  • Observability：trace / metric / log
  • Sandbox：代码执行隔离
  • AGENTS.md / Skill 新：AAIF 标准，60k+ 项目使用

核心概念详解（一句话 + 类比 + 技术映射）

Agent（智能体）
能自主决策 + 调用工具 + 循环执行直到完成目标的 LLM 程序。
类比：员工。映射：ToolLoopAgent / LangGraph Agent / Mastra Agent。
Tool / Function Calling
Agent 可用的「外部能力」，用 JSON Schema 声明。
类比：工具箱。映射：MCP Server、Zod-tool、needsApproval。
Prompt
给 LLM 的「指令 + 上下文 + 格式约束」。项目级指令现由 AGENTS.md 承载（AAIF 标准，60k+ 项目）。
三大件：System / Context / Output Schema。
Output API v6+
AI SDK v6 起用 generateText({ output: Output.object({schema}) })；generateObject / streamObject 已废弃。
类型：Output.object / array / choice / json / text。
StateGraph（状态图）
节点(步骤) + 边(转移) + 共享 State 的有向图。JS 端 1.1 起可用 StateSchema（兼容 Standard Schema / Zod）。
类比：流程图引擎。映射：LangGraph.js StateGraph。
Checkpoint / Resume
每步 State 持久化到 DB，崩溃可断点继续。1.2 起 DeltaChannel 只存增量降低开销。
生产须用 PostgresSaver / SqliteSaver / RedisSaver / MongoSaver；MemorySaver 在 serverless 冷启动会丢失。
HITL / Interrupt
关键步骤暂停等人审批，批准后携带新 State 恢复。AI SDK v6 提供 needsApproval（可静态或动态函数）。
⚠ resume 时节点从顶部重跑，interrupt 前的副作用必须幂等。
MCP 2026-07-28 新
工具「USB 标准」，本版改为无状态协议核心：无握手、无 Mcp-Session-Id，方法名走 Mcp-Method/Mcp-Name 头，server→client 用 MRTR。
扩展：Tasks、MCP Apps、EMA。弃用策略 12 个月窗口。
A2A v1.0 新
Agent 间互操作协议，Linux Foundation 治理。三层：数据模型 / 抽象操作 / 协议绑定。
与 MCP 区别：MCP 在 agent 内部连工具，A2A 在 agent 之间通信，生产系统两者都用。
RAG
检索知识 → 拼进 Prompt → 生成。AI SDK v6 内置 rerank()；Mastra 支持 GraphRAG 快照序列化避免每次重建。
流程：chunk → embed → store → retrieve → rerank → cite。
DeepAgent
「全 harness」——planning + context management + delegation 开箱即用；任何 LangGraph 图都可作为 sub-agent 接入。
v0.7 基础输入 token 降 65%。安全模型：trust the LLM，边界须在 tool/沙箱层强制。
Harness（运行时/控制面）
承载 Agent 执行的平台层：生命周期、队列、并发、资源、隔离、观测。
映射：LangGraph Server / LangSmith Deployment（原生支持 A2A & MCP）/ Mastra Server。
Sandbox
隔离环境执行不可信代码。2026 选型更迭：Daytona 已闭源自托管不可用。
E2B（Firecracker microVM）/ Modal（gVisor + GPU）/ 自托管 OpenSandbox·Microsandbox。
Evals / Observability
golden set + LLM-as-judge；trace + metric + cost。
LangSmith 2026-05 起核心迁移到 SmithDB（Rust 列式），核心体验最高快 15x。
一句话理清关系：MCP 让 Agent「会用工具」，A2A 让 Agent「会找同事」，RAG 是「给它看资料」，Prompt/AGENTS.md 是「教它做事」，Harness 是「给它办公室」，Sandbox 是「给它实验室」，Evals 是「给它 KPI」。

七、给你的专属学习策略

概念先行 1 周（W1）
先把第二节概念地图读透做成 cheatsheet。Agent 技术的混乱大多源于概念混用，地图建立后学每项技术都很快。
TS 一栈到底，Python 只做对照
全链路 TypeScript。Python 只在 W5（per-node timeout / error_handler 是 Python-only）、W9（DeepAgent backend protocol）做对标实验，不切换主语言。
按「价值密度」排序
Prompt/Output API/StateGraph/Checkpoint（核心）→ MCP/A2A（互操作）→ RAG/DeepAgent（增强）→ Harness/Sandbox（生产化）。不要把 RAG 当入门。
警惕版本时效性（本版最大风险）
MCP 2026-07-28、A2A v1.0、AI SDK v7、Mastra v1 都是近期破坏性更新。学每项技术前先开官方 changelog 核对；教程代码若出现 initialize 握手、generateObject、Mastra 0.x API，说明已过时，直接跳过。
每个阶段交付「可运行系统」
W2 解析器、W4 状态图、W5 持久化、W6 MCP gateway、W9 DeepAgent、W12 eval gate。宁可不完美，不可只停留在教程。
优先级铁律（时间不足时）
保四弃多：checkpoint · approval · eval gate · sandbox。这四项是「企业级」分界线。
