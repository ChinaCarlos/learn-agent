<DemoBox title="单 run 成本熔断" goal="演示风险表里「单 run > $5」如何变成代码，而不是事后看账单后悔。">

```ts
export class BudgetGuard {
  constructor(
    private readonly limitUsd: number,
    private spent = 0,
  ) {}

  charge(tokens: number, usdPerMillion: number) {
    const add = (tokens / 1_000_000) * usdPerMillion;
    if (this.spent + add > this.limitUsd) {
      throw new Error(`budget_exceeded: ${this.spent.toFixed(4)} + ${add.toFixed(4)} > ${this.limitUsd}`);
    }
    this.spent += add;
    return this.spent;
  }
}

const guard = new BudgetGuard(5);
guard.charge(200_000, 5); // 约 $1，通过
```

验收：把 `limitUsd` 改成 `0.01` 再跑必须抛错。W9 / W10 的「预算耗尽优雅停止」都调用同一类。
