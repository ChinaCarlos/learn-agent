<DemoBox title="最小 eval gate：JSON 契约不通过就失败" goal="演示「评测不是看感觉」。W12 会把 LLM-as-judge 接到同一函数。">

```ts
import { z } from 'zod';

const Artifact = z.object({
  stories: z.array(z.object({
    id: z.string(),
    ac: z.array(z.string()).min(1),
  })).min(1),
  citations: z.array(z.string()).default([]),
});

export function evalGate(input: unknown) {
  const parsed = Artifact.safeParse(input);
  if (!parsed.success) {
    return { pass: false, reason: 'schema', issues: parsed.error.issues };
  }
  const missingAc = parsed.data.stories.filter(s => s.ac.length === 0);
  if (missingAc.length) {
    return { pass: false, reason: 'empty_ac' };
  }
  return { pass: true };
}

if (!evalGate({ stories: [] }).pass) {
  throw new Error('eval gate failed');
}
```

验收：空 stories 必须抛错。把它写成 `pnpm test:eval`，W12 再换成 30+ golden set。
