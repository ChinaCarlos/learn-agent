## 学习目标

1. 记住六阶段和每阶段的唯一里程碑。
2. 按价值密度排序：先核心，后互操作，再增强，最后生产化。
3. 用一个小脚本把周计划变成可勾选的 JSON，后面每周更新状态。

<DemoBox title="用日期算出你现在该处在哪一周" goal="把路线图变成程序，避免「学着学着不知道自己在哪」。">

```ts
const START = new Date('2026-09-03T00:00:00+08:00');

export const WEEKS = [
  { id: 1, theme: '概念扫盲', milestone: '聊天/工具 UI + cost' },
  { id: 2, theme: 'Prompt', milestone: 'PRD → JSON' },
  { id: 3, theme: 'LangChain.js', milestone: 'MCP 工具 + 记忆' },
  { id: 4, theme: 'LangGraph 入门', milestone: '三节点图' },
  { id: 5, theme: 'Durable', milestone: 'kill 后恢复' },
  { id: 6, theme: 'MCP', milestone: '无状态 server' },
  { id: 7, theme: 'A2A', milestone: '3 角色 trace' },
  { id: 8, theme: 'RAG', milestone: '带 citation' },
  { id: 9, theme: 'DeepAgent', milestone: '预算内拆任务' },
  { id: 10, theme: 'Harness', milestone: '队列+并发+成本' },
  { id: 11, theme: 'Sandbox', milestone: '注入被拦截' },
  { id: 12, theme: 'Evals', milestone: 'CI 门禁' },
  { id: 13, theme: 'OTel', milestone: '端到端 trace' },
  { id: 14, theme: '生产化', milestone: '50 任务+回滚' },
] as const;

export function currentWeek(today = new Date()) {
  const diff = Math.floor((today.getTime() - START.getTime()) / 86400000);
  const index = Math.min(13, Math.max(0, Math.floor(diff / 7)));
  return WEEKS[index];
}
```

验收：把系统日期理解为 2026-09-10 时应返回 W2。把这个函数接到学习仓库首页。
