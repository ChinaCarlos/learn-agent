## 本周目标

1. 用 StateGraph 实现 Analyst → Specifier → Planner 三节点。

4. 页面用 React Flow 或简表展示每步 state diff。

<DemoBox title="带循环上限的条件路由" goal="三节点图的关键不是 LLM，而是图自己能拒绝往下走。">

```ts
type S = { prd: string; analysis: string; loops: number };

export function routeAfterAnalyze(state: S): 'analyze' | 'specify' {
  if (state.analysis.length < 40 && state.loops < 2) {
    return 'analyze';
  }
  return 'specify';
}
```

把它接到 `addConditionalEdges("analyze", routeAfterAnalyze, { analyze: "analyze", specify: "specify" })`。验收：输入「做个东西」会重试；输入完整 PRD 一次通过。
