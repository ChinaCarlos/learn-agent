## 本周目标

1. 建立 ≥30 条 golden set：输入、期望约束、标签。
2. 离线 eval 可本地复现。
3. 至少一种 LLM-as-judge（相关性 / 是否引用 source）。
4. GitHub Actions 或本地 `pnpm test:eval` 失败码为 1。

<DemoBox title="CI 可复现的 eval runner" goal="把第 6 章的 evalGate 扩成数据集循环。">

```ts
import { evalGate } from '../ch06/evalGate';

type Case = { id: string; output: unknown; expectPass: boolean };

export function runEval(cases: Case[]) {
  const failed = cases.filter(c => evalGate(c.output).pass !== c.expectPass);
  if (failed.length) {
    console.error(failed.map(f => f.id).join(','));
    process.exit(1);
  }
}
```

验收：插入一条 `expectPass: true` 但 `stories: []` 的用例，命令行退出码为 1。
