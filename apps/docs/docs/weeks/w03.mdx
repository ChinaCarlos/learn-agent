<DemoBox title="带审批的写工具" goal="证明工具链里「读自动、写暂停」。后续 HITL 只是把这个开关接到图上。">

```ts
type ToolResult =
  | { type: 'ok'; data: unknown }
  | { type: 'needs_approval'; tool: string; args: unknown };

export async function runTool(name: string, args: unknown): Promise<ToolResult> {
  if (name.startsWith('write') || name.startsWith('update')) {
    return { type: 'needs_approval', tool: name, args };
  }
  if (name === 'repo.search') {
    return { type: 'ok', data: [{ path: 'apps/web/app/page.tsx', snippet: 'export default function Page()' }] };
  }
  throw new Error(`unknown_tool: ${name}`);
}
```

验收：`runTool("writeFile", { path: "x" })` 返回 `needs_approval`；search 直接 ok。把这个函数接到聊天的 tool execute 里。
