## 本周目标

1. checkpointer 换成 PostgresSaver（本地可用 Docker Postgres）。
2. 审批节点 `interrupt`，批准后 `Command.resume`。
3. kill worker 后用同一 `thread_id` 恢复。
4. interrupt 前的副作用可重入。

<Callout tone="danger" title="resume 从节点顶部重跑">
  若你在 interrupt 之前已经 insert 过一行 DB，重跑会再 insert 一次。所以必须幂等，不能只靠「我记得跑过了」。
</Callout>

<DemoBox title="可恢复的审批闸门" goal="用最小结构模拟 interrupt/resume。接上官方 Command.resume 时保持同一语义。">

```ts
type Run = { threadId: string; node: string; status: 'running' | 'interrupted' | 'done'; cursor: number };

const db = new Map<string, Run>();

export function checkpoint(run: Run) {
  db.set(run.threadId, run);
}

export function killAndRestore(threadId: string) {
  return db.get(threadId); // 模拟新进程只认识 Postgres
}

export function resume(threadId: string) {
  const run = db.get(threadId);
  if (!run || run.status !== 'interrupted') {
    throw new Error('not_interrupted');
  }
  run.status = 'running';
  return run;
}
```

验收：`checkpoint` → 丢掉内存里的 worker 变量 → `killAndRestore` 仍能 `resume`。然后再换成官方 PostgresSaver。
