策略比信息更值钱。本章把六条策略写成仓库里的强制约定，后续 Agent 与你自己都按同一份文件做事。

## 学习目标

1. 把六条策略背成可执行规则，而不是鸡汤。
2. 在学习仓库根目录落地 AGENTS.md（AAIF 标准，60k+ 项目在用）。
3. 规定每周五的复盘问题和每周日的预读材料。

<DemoBox title="学习仓库根目录 AGENTS.md" goal="项目级指令用 AGENTS.md 承载，而不是散落在聊天记录里。W2 会把它真正接到 Prompt。">

```md
# AGENTS.md

## 栈
- 主语言 TypeScript / ESM。禁止 require("ai")。
- Python 仅允许 apps/notebooks，且必须写对照结论。

## 过时 API 黑名单
- generateObject / streamObject
- MCP initialize 握手 / Mcp-Session-Id
- Mastra 0.x
- A2A v0.3
- Daytona self-host

## 交付
- 每周一个可运行里程碑。
- 写操作必须经过 approval。
- 没有 tenant 的接口禁止合并。

## 时间不够时
- 保 checkpoint、approval、eval gate、sandbox。
```

验收：把文件放在仓库根目录。W2 Demo 会读取它当 system prompt 的一部分。
