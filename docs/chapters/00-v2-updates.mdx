<DemoBox title="用 Output API 解析任务，而不是 generateObject" goal="同一输入，过时 API 与现行 API 对照。把过时版本留在注释里当反例。">

过时写法（看到就删）：

```ts
// BAD: generateObject 已废弃，不要学、不要抄
// const { object } = await generateObject({ model, schema, prompt })
```

现行写法（W1–2 直接用这个）：

```ts
import { generateText, Output } from 'ai';
import { z } from 'zod';

const TaskSchema = z.object({
  title: z.string(),
  owner: z.enum(['frontend', 'backend', 'qa']),
  hours: z.number().int().positive(),
});

export async function parseTask(prompt: string) {
  const { output, usage } = await generateText({
    model: 'openai/gpt-4.1-mini',
    output: Output.object({ schema: TaskSchema }),
    prompt,
  });
  return { task: output, tokens: usage?.totalTokens ?? 0 };
}
```

本地验收：输入「用 4 小时做登录页」应得到 `owner: "frontend"`，并且控制台能打印 token。
