## 关系一句话

MCP 让 Agent 会用工具，A2A 让 Agent 会找同事，RAG 是给它看资料，Prompt / AGENTS.md 是教它做事，Harness 是给它办公室，Sandbox 是给它实验室，Evals 是给它 KPI。

<DemoBox title="最小 Agent Loop：查天气再决定要不要带伞" goal="用 40 行 TypeScript 跑通 Thought → Action → Observation，不引入框架，先建立直觉。">

```ts
type WeatherTool = (city: string) => Promise<{ tempC: number; rain: boolean }>;

const weather: WeatherTool = async city => {
  // 真实项目里这里会变成 MCP tool
  return { tempC: city === 'seattle' ? 9 : 24, rain: city === 'seattle' };
};

export async function shouldBringUmbrella(city: string) {
  const thought = `需要 ${city} 的天气才能判断`;
  const observation = await weather(city); // Action + Observation
  const answer = observation.rain ? '带伞' : '不带伞';
  return { thought, observation, answer };
}
```

升级作业（仍在本章，不必上框架）：把 `weather` 的 JSON Schema 写出来，假装它是 MCP tool 描述；再写一个 `needsApproval`，当 `tempC < 0` 时暂停。
