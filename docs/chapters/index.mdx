## 每周怎么学

默认容量 **10–15 小时/周**。时间不够时只保四项企业级分界线：

1. checkpoint 可恢复
2. approval 能拦住写操作
3. eval gate 能让 CI 失败
4. sandbox 能隔离代码执行

<Callout tone="warn" title="版本时效是最大风险">
  教程里如果出现 initialize 握手、generateObject、Mastra 0.x、A2A v0.3，直接停看，改读官方 changelog。本站第三、第〇章列出了 2026-09-02 核实版本。
</Callout>
