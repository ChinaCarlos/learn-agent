## 核实版本表

| 技术 | 角色 | TS 选型 | 核实版本 |
| --- | --- | --- | --- |
| LangChain.js | LLM 抽象 / 工具 / RAG 积木 | `@langchain/core` | langchain 1.2.39 |
| LangGraph.js | 主编排 | `@langchain/langgraph` | JS 1.2.9 |
| Mastra | TS Agent / Workflow / Memory | `@mastra/core` | v1.62.0，需 Node 22.13+ |
| Vercel AI SDK | 模型 / 结构化输出 / 流式 UI | `ai` | v7.0.74，ESM only |
| MCP | 工具协议 | `@modelcontextprotocol/sdk` | 规范 2026-07-28 |
| A2A | Agent 互操作 | `a2a-js` | v1.0.0 |
| DeepAgent | 长程自主 | 自建或 `deepagents` | 0.7.8 |
| RAG | 检索增强 | LangChain retrieval + pgvector | rerank() + GraphRAG 快照 |
| Harness | 运行时 | LangGraph Server / Fastify | 原生 A2A & MCP |
| Sandbox | 隔离执行 | E2B / Modal / OpenSandbox | Daytona 自托管不可用 |
| Observability | 评测监控 | OTLP + LangFuse / Phoenix | LangSmith → SmithDB |

<DemoBox title="LangGraph.js 最小图：分析 → 计划" goal="用 StateSchema 风格的状态对象跑两个节点，验证主编排选型是否安装成功。">

```ts
import { StateGraph, Annotation, START, END } from '@langchain/langgraph';

const State = Annotation.Root({
  prd: Annotation<string>(),
  analysis: Annotation<string>(),
  plan: Annotation<string>(),
});

const graph = new StateGraph(State)
  .addNode('analyze', async state => ({
    analysis: `目标: ${state.prd.slice(0, 80)}`,
  }))
  .addNode('plan', async state => ({
    plan: `下一步: 把「${state.analysis}」拆成 3 个用户故事`,
  }))
  .addEdge(START, 'analyze')
  .addEdge('analyze', 'plan')
  .addEdge('plan', END)
  .compile();

export const run = (prd: string) => graph.invoke({ prd });
```

验收：`run("做一个登录页")` 返回的 state 同时有 `analysis` 和 `plan`。这就是 W4 三节点图的胚胎。
