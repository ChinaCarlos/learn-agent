<DemoBox title="同一份 Zod schema 打通 UI 与 API" goal="证明「一套语言」的价值：前后端共用 TaskDraft，而不是各写一份 JSON。">

```ts
// packages/agent/src/schema.ts
import { z } from 'zod';

export const TaskDraftSchema = z.object({
  title: z.string().min(4),
  stack: z.literal('typescript'),
  hours: z.number().min(1).max(20),
});
export type TaskDraft = z.infer<typeof TaskDraftSchema>;
```

```ts
// apps/api/src/health.ts
import Fastify from 'fastify';
import { TaskDraftSchema } from '@learn/agent';

const app = Fastify();
app.post('/drafts', async (req, reply) => {
  const parsed = TaskDraftSchema.safeParse(req.body);
  if (!parsed.success) {
    return reply.code(400).send(parsed.error.flatten());
  }
  return { ok: true, draft: parsed.data, runtime: 'fastify-ts' };
});
```

验收：用 curl 发错误 `stack: "python"` 必须 400；发 `typescript` 必须 200。这就是后面所有 Agent artifact 的原型。
