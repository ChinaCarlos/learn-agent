<Callout tone="danger" title="MemorySaver 不是架构">
  生产必须 PostgresSaver / SqliteSaver / RedisSaver / MongoSaver。MemorySaver 在 serverless 冷启动会丢状态，W5 会专门打这个坑。
</Callout>

<DemoBox title="Fastify gateway：租户头进编排层之前必须存在" goal="演示产品层请求如何被架构边界拦住。没有 x-tenant-id 不得调用 graph。">

```ts
import Fastify from 'fastify';

const app = Fastify();

app.addHook('preHandler', async (req, reply) => {
  const tenant = req.headers['x-tenant-id'];
  if (typeof tenant !== 'string' || tenant.length < 3) {
    return reply.code(401).send({ error: 'missing_tenant' });
  }
  req.headers['x-tenant-id'] = tenant;
});

app.post('/runs', async req => {
  const tenant = req.headers['x-tenant-id'];
  return {
    runId: crypto.randomUUID(),
    tenant,
    layer: 'orchestration',
    checkpointer: 'PostgresSaver',
  };
});
```

验收：缺头返回 401；带 `x-tenant-id: acme` 返回 runId。W8 的 ACL 与 W11 的 RBAC 都挂在这个钩子上长出来。
