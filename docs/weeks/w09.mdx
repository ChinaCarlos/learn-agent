DeepAgent 是「全 harness」：planning + context management + delegation 开箱即用。任何 LangGraph 图都可作为 sub-agent。安全模型是 trust the LLM，边界必须在 tool / 沙箱层强制。

## 本周目标

1. 大任务能拆成子任务图并执行。
2. 预算耗尽时优雅停止，留下部分 artifact。
3. 终止条件写死：完成 / 失败 / 超预算 / 超步数。
4. 可选：Python 对照 backend protocol，结论迁回 TS。

<DemoBox title="带终止条件的任务拆解器" goal="DeepAgent 的核心不是更长的 prompt，而是停得下来。">

```ts
import { BudgetGuard } from '../../lib/budget';

type Sub = { id: string; title: string; status: 'todo' | 'done' | 'skipped' };

export function* runDeep(goal: string, subs: Sub[], guard: BudgetGuard) {
  for (const sub of subs) {
    try {
      guard.charge(80_000, 5);
      sub.status = 'done';
      yield { goal, sub, ok: true };
    } catch (error) {
      sub.status = 'skipped';
      yield { goal, reason: 'budget_exceeded', remaining: subs.filter(s => s.status === 'todo') };
      return;
    }
  }
}
```

验收：3 个子任务、极小预算时，至少 1 个 skipped，并且生成器停止而不是抛到进程外未捕获。
