现在才允许认真做 RAG。流程：chunk → embed → store → retrieve → rerank → cite。跨 tenant 检索必须为空。GraphRAG 快照是 stretch。

## 本周目标

1. 把本学习站的 markdown（或内部规范）入库 pgvector。
2. 回答必须带 source 路径 + 片段。
3. tenant A 的 embedding 对 tenant B 查询返回空。
4. 使用 AI SDK `rerank()` 或等价重排，而不是只取向量 TopK。

<DemoBox title="强制 citation 的拼装器" goal="即使还没接向量库，先把「无 source 不回答」写成死规则。">

```ts
type Hit = { path: string; text: string; score: number };

export function buildRagPrompt(question: string, hits: Hit[]) {
  if (hits.length === 0) {
    return { abort: true, reason: 'no_hits_for_tenant' };
  }
  const context = hits.map((h, i) => `[#${i + 1} ${h.path}] ${h.text}`).join('\n');
  return {
    abort: false,
    prompt: `只根据资料回答。每句事实后加 [#n]。资料不足就说不知道。\n${context}\n问题：${question}`,
  };
}
```

验收：`hits=[]` 必须 abort，不得调用模型（省钱且避免幻觉）。
