<DemoBox title="AI SDK v7：流式聊天 + 本地 tool + usage" goal="里程碑的最小实现。可直接放进 `app/api/chat/route.ts` 思路中。">

```ts
import { streamText, tool } from 'ai';
import { z } from 'zod';

const lookupStackPolicy = tool({
  description: '查询本学习方案的栈策略',
  inputSchema: z.object({ topic: z.string() }),
  execute: async ({ topic }) => ({
    topic,
    policy: 'TypeScript 主栈贯穿生产，Python 只做对照。',
  }),
});

export async function chat(prompt: string) {
  const result = streamText({
    model: 'openai/gpt-4.1-mini',
    prompt,
    tools: { lookupStackPolicy },
  });
  return result.toUIMessageStreamResponse();
}
```

页面侧显示 `message.parts` 里的 text 与 tool-invocation，并在结束时读取 usage。验收：问「我要不要学 Python 当主栈？」必须出现 tool 调用，而不是模型瞎编。
